# Timezone

## 存储与传输

- 接口层、数据层统一使用 UTC
- 展示层必须根据当前客户端时区自行转换
- 时区标识符**必须使用 IANA 名称**（如 `Asia/Kuala_Lumpur`），**禁止数字偏移**（如 `+8`、`+08:00`）——偏移不处理夏令时，跨时区扩展后历史数据会出现偏差

## 实体时区字段

| 字段 | 表 | DB 约束 | 默认建议值 | 说明 |
|------|---|--------|----------|------|
| `tenant.timezone` | tenant | NOT NULL | `Asia/Kuala_Lumpur` | 租户时区，注册时带建议值必选；影响报表分桶与工作时间窗口判定 |
| `instance.timezone` | instance | NOT NULL | 继承 `tenant.timezone`（表单预填） | 实例时区；新建实例表单预填租户时区；带建议值必选 |

- 报表「今日 / 本周 / 本月」分桶用 `instance.timezone`
- 工作时间窗口判定（R24）用 `instance.timezone`
- 客户端资源展示、任务时间显示用客户端浏览器时区（现有规则）
- 多实例汇总报表：各实例用自己的 `instance.timezone` 分桶后再汇总

## 兜底规则

若 `tenant.timezone` 意外为空（仅允许数据迁移场景）：
- 服务端降级 `UTC`（显式、可预测）
- 业务管理端仪表盘展示警告横幅提示配置缺失
- 不静默降级，不使用服务器系统时区

## 时区选择器 UI 约定

表单中时区字段使用「带建议值必选 + 检测提示」模式，禁止「跟随系统」默认选项：

```
实例时区 *
┌─────────────────────────────────────┐
│ Asia/Kuala_Lumpur                 ▼ │  ← 预填值（租户时区 or 系统默认）
└─────────────────────────────────────┘
  📍 检测到你的设备时区：Asia/Singapore (+08:00)  [使用此时区]
     ↑ 仅当浏览器检测值 ≠ 预填值时才显示此行
```

- 检测值 = 预填值：不显示提示行，无噪音
- 检测值 ≠ 预填值：显示一行小提示，含 IANA 名 + UTC 偏移，点击才应用
- 说明文案（固定展示）：「影响报表时间和工作时间窗口判断，请确认」
- 此约定适用于所有含时区字段的表单（租户注册、实例新增/编辑）
