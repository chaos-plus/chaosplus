# FLOWCHART

> 本文件定义流程图与状态机的**通用绘制规范**。具体业务流程随版本定义在对应 `prd.md`。

---

## 业务流程图

绘制规范：

- 每条流程必须有明确的**起点与终点**，不留悬空分支
- 关键节点标注**触发条件**与**操作角色 / 端**
- 覆盖主流程（Happy Path）+ **异常分支**（失败、超时、取消、回滚）
- 跨端流程标注各端职责与交接点（如 提交端 → 处理端 → 完成端）

## 数据流转图 / 状态机

绘制规范：

- **状态枚举完整**：列出全部状态，无未定义或含义不明的状态
- **默认状态明确**：标明初始状态与终止状态
- **流转条件显式**：每条状态迁移标注触发条件，无逻辑跳跃
- **非法流转拦截**：未声明的迁移视为非法，必须被拦截
- **幂等与并发**：标注重复触发、并发操作下的状态处理
- **跨端一致**：同一业务实体在多端的状态最终一致（联动 `3.ARCH.md` 闭环原则）

### 状态机文档要素

| 要素 | 说明 |
|------|------|
| 状态列表 | 全部状态及含义 |
| 初始 / 终止状态 | 进入与结束节点 |
| 迁移表 | 当前状态 + 触发条件 → 目标状态 |
| 异常处理 | 失败 / 超时 / 取消 对应的状态归属 |
| 操作记录 | 关键迁移是否需留痕可溯源 |
