# PRD 模板（总览 + 分端）

> **用法**：复制对应模板——总览存为 `prd.md`，每端一份 `prd-{端}.md`（customer / mch / pos / kds / sys / ops / www / num）。
> `{…}` 为占位符；标注「示例」的表格行展示要求的精确度，须替换为真实内容。
> 写法必须满足 `3.PROTOTYPE.md`「PRD 写作规则（三读者）」：可判定、ID 可追溯、规则表格化、行为三段式、测试可推导。
> 不适用的章节写「无 + 一句原因」，**不得删章节、不得留空**。
> **排版与符号**：头部引用块只放一行元信息，全文性约定入表格；**组件清单 / 操作清单 / 校验规则一律表格，禁止段落式罗列**（同构页不省略表格，可注明「与 P{n} 同构」）；页面功能用竖排编号列表；权限 / 操作记录 / i18n / 原型等尾部字段每项独立一行；章节引用写「第 N 节」，**不用 § 符号**；长串用例编号放表格「关联用例」列，不混入正文；**ID 引用带简短标签 `ID（标签）`、数字枚举状态配语义名 `20（已下单锁定）`，不留裸编号**（见 `3.PROTOTYPE.md` 第 2 条 ID 体系）。
> **克隆约定**（`2.META.md`）：克隆是纯前端预填行为，提交走新增接口（POST），**任何模块都不设独立 clone 接口**。
> **Loading 与并发**：各页「状态与反馈」遵循 `3.DESIGN.md`「网络请求 Loading 与并发处理规范」，页内不重复定义。
> **总览 / 分端分工（去重铁律）**：`prd.md` 只放**跨端共享**内容（术语 / 数据模型 / 状态机 / 跨端流程 / R 规则 / 验收与 DoD）；`prd-{端}.md` 放**该端全部细节**（端内流程 / 页面 / 接口 / 白名单等）。同一内容只允许一个定义处，另一处引用。**单端版本**：流程全在分端（总览第 8 节标「无跨端流程」）；分端的范围与自查只写「同总览 + 差异」，不复述。
